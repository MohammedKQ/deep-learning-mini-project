# 🫀 ECG Anomaly Detection

## 📌 Overview

This project detects abnormal heartbeats (anomalies) from ECG signals using an Autoencoder model.

The model learns normal patterns and identifies anomalies based on reconstruction error.

---

## 📂 Dataset

MIT-BIH Arrhythmia Dataset
https://www.kaggle.com/datasets/shayanfazeli/heartbeat

* 0 → Normal
* 1–4 → Anomaly

---

## ⚙️ Approach

* Data preprocessing and normalization
* Autoencoder model (Keras)
* Reconstruction error (MSE)
* Threshold-based anomaly detection
